# JARVIS для Windows 10/11: техническое задание

> Источник: разбор 5 референсных видео (Luxify Assistant / «Джарвис»), покадрово и по звуку.
> Цель: повторить **весь** показанный функционал и внешний вид, сделать всё рабочим, **офлайн по умолчанию**, с минимальным потреблением ресурсов.
> Читай только нужный раздел по якорю `§N`, а не весь файл.
> Проект **личный и приватный** (приватный GitHub-репозиторий, некоммерческое использование фанатом фильма). Код из референсов (§13) можно свободно брать и адаптировать, оставив ссылку на источник в комментарии. Код и бренд Luxify закрыты: их функции и стиль повторяем своей реализацией.

**Целевое железо:** ASUS TUF Gaming F15, **8 ГБ RAM (в простое Windows 11 + Chrome уже занимают ~7 ГБ)**, NVIDIA RTX 3060 Laptop 6 ГБ VRAM, Windows 11. Главное ограничение — оперативная память: каждый мегабайт на счету.

---

## §0 Ключевые требования (не нарушать)

1. **Офлайн-first.** Распознавание речи, wake word, синтез голоса, выполнение команд, редактор, паки (и опциональный локальный ИИ) работают без интернета. Сеть нужна только для погоды, новостей, курса валют и веб-поиска. Без сети Джарвис говорит: «Сэр, нет подключения к интернету. Эта функция требует сети.» (голосом Джарвиса) и ничего не ломается.
2. **Голос Джарвиса из русского дубляжа фильма** (см. §6). Стандартные ответы звучат как в видео: «Да, сэр», «Загружается», «Запрос выполнен, сэр», «Всегда к вашим услугам, сэр», «Всегда рад помочь, сэр».
3. **Ресурсы** (§12): в простое (трей, окно закрыто, режим префикса) **≤ 60 МБ RAM** (жёсткий предел 100 МБ), CPU ≤ 1%. В простое работают только захват звука, VAD и крошечный детектор слова «Джарвис». Распознавание речи, нейро-TTS и UI загружаются по требованию и выгружаются после простоя (§12).
3a. **Без ИИ-модели (LLM) по умолчанию.** Всё ядро (голосовые команды, ответы голосом Джарвиса, редактор, паки, сборка сценариев из описания, презентации по шаблону, диалоги) работает **без LLM**. Маленькие модели распознавания речи (Vosk ~45 МБ) и синтеза голоса — это не «ИИ-чат», а обычные офлайн-компоненты, без них компьютер не поймёт голос. Локальный LLM — отдельный опциональный модуль «Jarvis AI» (§7), **выключен по умолчанию**, реализуется последним этапом.
4. **Язык:** русский (интерфейс, распознавание, ответы). Архитектура i18n, английский — задел на потом.
5. **Windows 10 и 11 x64.** Установщик NSIS/MSI, автозапуск, трей.
6. **Безопасность:** опасные действия (выключение, удаление, произвольный shell) идут только через подтверждение (§4.6). LLM вызывает только whitelisted-инструменты.

## §1 Стек и архитектура

| Слой | Технология | Почему |
|---|---|---|
| Оболочка/UI | **Tauri 2** + **Svelte 5 + TypeScript + Vite** | Малый вес. WebView2 уже есть в Win10/11. Окно можно уничтожать при сворачивании в трей (0 RAM на UI) |
| Ядро | **Rust** (workspace crates) | Низкое потребление RAM, прямой WinAPI через крейт `windows` |
| Захват звука | `cpal` (WASAPI) | 16 kHz mono, кольцевой буфер |
| VAD | Silero VAD (ONNX, через sherpa-onnx) | Лёгкий |
| Wake word «Джарвис» | **Rustpotter** (готовые `jarvis-*.rpw` из Priler/jarvis) → fallback: Vosk grammar-mode `["джарвис","[unk]"]` | Офлайн, без ключей |
| STT команд | **Vosk small-ru-0.22** (grammar/free mode), грузится после wake word с буферизацией звука, держится тёплым `stt_keep_warm_sec` (по умолчанию 120) и выгружается | ~45 МБ на диске, быстро на CPU, в простое 0 МБ |
| STT свободной речи (только модуль AI, опционально) | **GigaAM v2 (sherpa-onnx)**, ленивая загрузка | Лучшее качество для русского офлайн |
| TTS | 1) пак готовых фраз (WAV), 2) **Piper/VITS через sherpa-onnx** (голос Джарвиса после дообучения, §6), 3) Windows SAPI как fallback | Всё офлайн |
| NLU | точный/нечёткий матчинг фраз + словарь синонимов → (опц.) эмбеддинги MiniLM ONNX int8, ленивая загрузка → LLM только если модуль AI включён | Каскад: дёшево → дорого |
| Локальный LLM (опционально, выкл) | **llama.cpp `llama-server`** CUDA-сборка, все слои на GPU (RTX 3060 6 ГБ), sidecar по требованию | Почти не трогает RAM: модель в видеопамяти |
| Хранилище | SQLite (`rusqlite`) для истории/настроек + JSON для команд/паков | Паки легко шарить |
| Пульт с телефона | `axum` HTTP+WebSocket в ядре, PWA | Работает в LAN без интернета |
| Автоматизация Office | COM (`windows` crate, IDispatch) для PowerPoint/Word | Презентации, форматирование |

**Процессы:**
- `jarvis.exe`: ядро, работает постоянно. В простое внутри только аудио-поток, VAD, wake word, исполнитель, IPC. Vosk/TTS подгружаются по требованию.
- `llama-server.exe`: только если модуль AI включён; стартует по первому ИИ-запросу, убивается через `ai.idle_unload_sec` (по умолчанию 60).
- Нейро-TTS и GigaAM грузятся в ядро лениво и выгружаются по таймеру простоя.
- Окно UI и окно-аватар: отдельные Tauri-окна. Главное окно уничтожается при «в трей» и пересоздаётся при открытии.

**Структура репозитория:**
```
crates/core      # аудио, wake, stt, nlu, executor, tts, config, db, ipc
crates/win       # WinAPI-обёртки: окна, громкость, питание, COM, UIA, ввод
crates/ai        # llama-server менеджер, tool-calling, сборщик сценариев
crates/remote    # axum + PWA
crates/app       # Tauri main
frontend/        # Svelte UI
packs/           # JSON-паки команд
voices/          # паки голосов (фразы) + конфиги TTS
tools/voice-train/  # пайплайн дообучения голоса Джарвиса (Python, офлайн, один раз)
tests/fixtures/  # WAV-фикстуры для тестов распознавания
```

## §2 Голосовой цикл и режимы

### §2.1 Поток
`mic → VAD → wake word → (звук/фраза «Слушаю, сэр» опционально) → STT команды → NLU → executor → голосовой ответ → история`

- После wake word окно слушания длится `listen_timeout_sec` (по умолчанию 6 с) или до конца фразы по VAD.
- Фраза целиком за раз: «Джарвис, включи музыку» (wake word и команда в одной фразе без паузы) обязательно должна работать. Если Vosk выгружен: звук после wake word пишется в буфер, модель грузится (цель ≤ 400 мс с SSD), буфер скармливается распознавателю, ни одно слово не теряется. Сразу после wake word играет короткий звук/анимация, чтобы задержка не ощущалась.
- Continuous follow-up: 5 с после ответа можно говорить без «Джарвис» («Спасибо, Джарвис», «Закрой окно»).
- Barge-in: если Джарвис говорит и пользователь сказал «Джарвис» / «стоп», речь прерывается.

### §2.2 Режимы (из видео, панель управления и настройки)
| Режим | Поведение | Голосовая фраза переключения (по умолчанию, редактируется) |
|---|---|---|
| **Режим префикса** (вкл по умолчанию) | Команды только после «Джарвис» | «Перейди в режим префикса» |
| Без префикса | Слушает команды постоянно (Vosk в grammar-mode по словарю всех фраз, чтобы не ловить мусор). Vosk держится в памяти, в настройках показать «+~100–300 МБ RAM» | «Выключи режим префикса» |
| **Тихий режим** | Без голосовых ответов, только короткий звук и визуал | «Перейди в тихий режим» |
| **Выключить микро** | Микрофон закрыт полностью. Включается только кнопкой/горячей клавишей/с телефона | «Хватит слушать» |
| Чувствительность префикса | Слайдер 0–100% (порог wake word) | — |

### §2.3 Горячие клавиши
Push-to-talk (по умолчанию `Ctrl+Alt+J`), показать/скрыть окно, mute микрофона. Настраиваются.

### §2.4 Хлопки (идея из MateuszMlynekHub/launcher, реализовать самим)
Опциональный триггер «двойной хлопок» (энергетический детектор + классификатор, вкл/выкл, чувствительность) → запускает выбранную команду или профиль рабочего окружения (§10.2).

## §3 Интерфейс (как на видео)

### §3.1 Визуальный стиль
- Тёмная графитовая тема (`#15171C`–`#1E2128`), стеклянные панели (glassmorphism: полупрозрачность + backdrop blur), скругления 12–16 px, тонкие границы `rgba(255,255,255,.06)`.
- Акцент по умолчанию синий `#3B82F6`. Палитра темы (свотчи в настройках): синий, фиолетовый, пурпурный, зелёный, оранжевый, красный, белый + свой цвет.
- Шрифт: Inter / Segoe UI Variable. Заголовки разделов капсом («ОСНОВНОЕ ОКНО», «НАСТРОЙКИ», «РЕДАКТОР КОМАНД», «ДОПОЛНЕНИЯ»).
- **Орб**: концентрические размытые круги акцентного цвета справа в окне. Спокойно «дышит» в простое, пульсирует по амплитуде голоса пользователя и TTS. На Canvas/WebGL, 60 fps, при скрытом окне рендер останавливается.
- Все переходы плавные (150–250 мс), при выключенных «Анимациях» мгновенные.

### §3.2 Каркас окна
- Frameless-окно со своими кнопками свернуть/закрыть. Настройки «Окно поверх» и «Прозрачность» / «Размытие» (Mica/Acrylic на Win11, fallback CSS на Win10).
- Левый сайдбар (иконки + тултипы): Главная, Редактор команд, Дополнения, Luxify-AI → **«Jarvis AI»**, Настройки, внизу Профиль/О программе.
- **Полоса слушания** (pill сверху окна и в оверлее): иконка микрофона в кружке акцентного цвета + распознаваемый текст вживую (подсветка слова «Джарвис») + анимированная волна/точки справа.

### §3.3 Главная (дашборд)
Плитки: Jarvis AI (если модуль выключен — «Выключен») · «N команд» (живой счётчик) · Редактор команд · Игры · Браузер · Система. Клик открывает раздел/фильтр команд.

### §3.4 Основное окно
- **История команд**: список «фраза пользователя → статус» (Выполнено / Ошибка / Отменено / Нет сети), время, повтор по клику. Хранится в SQLite, последние 500.
- **Панель управления** (тумблеры): Режим префикса, Тихий режим, Анимация аватара, Окно поверх. Слайдер «Громкость» (громкость голоса Джарвиса, %).
- Большая кнопка микрофона (push-to-talk кликом). Орб справа.

### §3.5 Трей
Иконка меняет состояние: слушает / выполняет / микрофон выключен. Меню: Открыть, Микрофон вкл/выкл, Тихий режим, Профили, Выход.

### §3.6 Живой аватар на рабочем столе
Отдельное прозрачное click-through окно поверх всего (угол экрана, позиция перетаскивается в режиме настройки). Орб реагирует на голос. Вкл/выкл тумблером «Анимация аватара». Лёгкий рендер, выключается при полноэкранных играх (детект fullscreen foreground).

### §3.7 HUD-скин (видео 27)
Опционально: при активации поверх экрана показывается анимированный HUD в стиле Iron Man (круговые шкалы, проценты, красно-синие дуги), исчезает после ответа. SVG/CSS-анимация, своя отрисовка. Тумблер в настройках «HUD при активации».

## §4 Команды: модель, матчинг, выполнение

### §4.1 Модель данных (JSON, `packs/*.json` и пользовательские `%APPDATA%/Jarvis/commands.json`)
```json
{
  "id": "chrome.open",
  "folder": ["Управление Chrome"],
  "name": "Открыть браузер",
  "phrases": ["браузер", "хром"],
  "optional": ["открой", "запусти", "включи", "пожалуйста", "ну-ка", "давай"],
  "actions": [
    {"type": "Launch.File", "path": "%CHROME%", "args": ""},
    {"type": "Lux.PauseMS", "ms": 300}
  ],
  "reply": {"clips": ["ok"], "text": "Да, сэр"},
  "confirm": false,
  "chainable": true,
  "slots": {}
}
```
- **Обязательные фразы (phrases):** хотя бы одна должна прозвучать. **Необязательные (optional):** могут быть или не быть. Демо из видео: «браузер» ✓, «открой браузер» ✓, «открой браузер пожалуйста» ✓.
- **Слоты:** `{число}`, `{время}`, `{текст}`, `{приложение}`. Пример: «громкость на {число}», «выключи компьютер через {время}».
- Переменные путей: `%CHROME%`, `%STEAM%`, `%SPOTIFY%`… резолвятся автоматически (реестр, Start Menu, UWP AppsFolder).

### §4.2 Матчинг (каскад)
1. Нормализация: нижний регистр, ё→е, числительные → числа (**русский парсер числительных**: «пятьдесят» → 50, «два часа» → 7200 с, «полчаса», «через минуту»), удаление филлеров.
2. Точное совпадение по индексу фраз, затем fuzzy (Levenshtein/Jaro по токенам, порог настраивается).
3. Эмбеддинги (MiniLM ONNX, косинус ≥ порога) по всем фразам.
4. Если не найдено → клип «не понял» («Простите, сэр, не понял команду»). Если включён модуль AI → LLM с tool-calling (§7).
- Цель: матчинг ≤ 30 мс на 1000 команд.

### §4.3 Связывание (Chain)
«Открой браузер **и** включи музыку» → разбиение по «и», «потом», «затем», «а ещё» → последовательное выполнение → в UI карточки «Открыть браузер ✓ Выполнено», «Включить музыку ✓ Выполнено». Флаг команды «Связывать» разрешает участие в цепочках.

### §4.4 Типы действий (executor, все реализовать)
**Запуск:** `Launch.File(path,args,workdir,admin?)`, `Launch.Url(url)`, `Launch.Uwp(aumid)`, `Launch.Find(name)` (поиск в меню Пуск/реестре/UWP; «найдено в Пуске»), `Process.Kill(name)`.
**Окна:** `Window.Close` (активное), `Window.Minimize/Maximize/Restore`, `Window.MinimizeAll` («сверни все окна»), `Window.Focus(process|title)`, `Window.Snap(left|right|top)`, `Window.MoveToMonitor(n)`, `Window.Fullscreen`.
**Ввод:** `Keys.Press("ctrl+shift+s")`, `Keys.Type(text)`, `Keys.Hold(key,ms)`, `Mouse.ToCoords(x,y)`, `Mouse.ClickLeft/ClickRight/Double(x?,y?)`, `Mouse.LC(n)`, `Mouse.Scroll(dy)`. Через `SendInput`.
**Звук/медиа:** `System.VolumeSet(0..100)`, `VolumeUp/Down(step)`, `Mute/Unmute` (Core Audio `IAudioEndpointVolume`), `Media.PlayPause/Next/Prev/Stop` (VK_MEDIA_*), `Audio.SwitchDevice(name)`.
**Система:** `System.Shutdown/Restart/Sleep/Hibernate/Lock/Logoff(delay_sec)`, `System.CancelShutdown`, `System.PowerPlan(balanced|high|saver)`, `System.Brightness(0..100)` (WMI для ноутбуков), `System.Screenshot(region|full → папка)`, `System.OpenSettings(ms-settings:uri)`, `System.EmptyRecycleBin`, `System.WiFi/Bluetooth(on|off)`, `System.DND(on|off)`, `System.GameMode` (§4.7), `System.Clipboard(get|set)`, `System.Info` (время, дата, батарея, загрузка CPU/RAM вслух).
**Служебные:** `Lux.PauseMS(ms)`, `Lux.PauseSec(s)`, `Sound.PlayWav(path)`, `Speak(text|clip)`, `Ask(question)` (голосовое да/нет), `Run.Command(cmd|powershell)` (всегда с подтверждением, если не помечено доверенным), `Run.Command.Hidden`, `Timer(sec, then_command)`, `Reminder(time,text)`.
**Ассистент:** `Assistant.Mode(prefix|silent|mic_off, on|off)`, `Assistant.SetTheme(color)`, `Assistant.OpenPage(page)`, `Assistant.Repeat` (повторить последнюю), `Assistant.Cancel`.
**Office (COM):** `PowerPoint.NewPresentation(topic, slides?)` (шаблон, а с модулем AI — контент от LLM, §7.4), `PowerPoint.ApplyTheme(name|color)`, `PowerPoint.SetVariantColor(color)`, `Word.Bold/Italic/NewParagraph/Print/Save`, `Word.Dictate(text)`.
**UI Automation:** `UIA.Click(name|automationId, window)`, `UIA.SetText(...)`: для устойчивых к координатам команд.

Каждое действие: таймаут, результат `Ok/Err(msg)`, лог. При ошибке голосом «Сэр, не удалось выполнить: …» (коротко).

### §4.5 Контекст
Если в фокусе PowerPoint/Word, «измени цвет темы на фиолетовый» применяется к документу (видео 29). Иначе к теме Джарвиса. Команда может иметь `when: {foreground: "POWERPNT.EXE"}`.

### §4.6 Подтверждение (видео 30)
Диалог: иконка щита, «Подтверждение. Вы хотите выполнить команду "Выключить компьютер"?», кнопки [Подтвердить] [Отменить], внизу «Автоотмена через 30 сек.» и «🎙 или голосом: «да» / «нет»». Голосом Джарвис спрашивает: «Сэр, выполнить выключение компьютера?». По умолчанию включено для: выключение/перезагрузка/выход, Run.Command, Process.Kill системных процессов, удаление файлов.

### §4.7 Режимы ПК («режимы» из задачи)
Готовые команды: «игровой режим» (план питания «Высокая производительность», DND, закрыть фоновые из списка), «рабочий режим» (профиль приложений, §10.2), «режим фильма» (громкость, яркость, fullscreen), «ночной режим» (Night Light, громкость ниже). Все редактируемы как обычные сценарии.

## §5 Редактор команд (видео 26, 28, 30)

### §5.1 Древо
Слева дерево: **папки → команды → фразы** (корень «Джарвис»; примеры папок: Управление системой, Управление Chrome, Управление Spotify, Управление Photoshop, Управление Microsoft Word, Управление YouTube). Тулбар: новая папка / новая команда / новая фраза, удалить, дублировать, поиск, Сохранить. Drag&drop, вкл/выкл команды. Внизу хлебные крошки «Папка › Команда › Фразы».

### §5.2 Вкладки
«Редактор команд» | «Новая команда 1» (несколько открытых), кнопки [Отмена] [Сохранить].

### §5.3 Карточка команды
- **Название**, чекбоксы **Связывать** и **Подтверждать**.
- Кнопки: **+ Действие**, **Запись действий**, **✨ Создать с помощью AI**.
- **Список действий** (шаг за шагом): № | тип (`Launch.File`, `Keys.Press`, `Mouse.ClickLeft`, `System.VolumeSet`, `Launch.Url`, `Lux.PauseMS`/`PauseSec`, `Sound.PlayWav`, `Mouse.ToCoords`, `Mouse.LC`…) | параметр (с иконкой приложения, например «OBS Studio», «Google Chrome», «ctrl + shift + s», «960 540», «35») | кнопки ⏱ (задержка), 📁 (выбрать файл), ⊗ (удалить). Перетаскивание для порядка. Подсказки-чипы типов: Программа, Клавиши, Клик, Сайт, Пауза.
- **Фразы для активации** (обязательные, поле с чипами) и **Необязательные фразы** («открой, запусти, пожалуйста»). Живой предпросмотр совпадений: чипы «браузер ✓», «открой браузер ✓», «открой браузер пожалуйста ✓».
- Реплика ответа: клип из голосового пака или текст для TTS.
- Кнопка **▶ Тест**: выполнить без голоса.

### §5.4 Запись действий
Кнопка «● Запись действий 00:02 ■ Стоп»: глобальные хуки клавиатуры/мыши (low-level hooks) пишут клики с координатами и клавиши, паузы между ними (`Mouse.ClickLeft 642 518`, `Lux.PauseMS 850`). После «Стоп» шаги добавляются в список и редактируются. Запись не ловит клики по самому окну Джарвиса.

### §5.5 Создать с помощью AI (видео 26, 30)
Поле «Опишите задачу словами», например «Открой VS Code и Notion, а через 3 секунды включи Spotify» → [✨ Собрать] → статус «Собираю из действий…» → «AI создал сценарий. Готово — 4 шага»: Запустить программу (Visual Studio Code, «✓ найдено в Пуске») · Запустить программу (Notion) · Пауза (3 секунды) · Запустить программу (Spotify). Плюс предложенные фразы активации («рабочий режим», «начинаем работу») и необязательные («включи», «давай»).
- **Без LLM (по умолчанию):** свой офлайн-парсер описаний на русском: разбиение на шаги по «и / потом / затем / а через N секунд», словарь глаголов → типы действий (открой/запусти → Launch.Find, подожди/через N → Pause, нажми → Keys.Press, открой сайт → Launch.Url, громкость на N → VolumeSet, сверни/закрой → Window.*, включи музыку в X → Launch + Media.Play), имена приложений резолвятся через `Launch.Find` по индексу меню Пуск (fuzzy, синонимы «вс код» → Visual Studio Code). Фразы активации предлагаются из названий приложений и шаблонов. Должен покрывать оба примера из видео.
- **С модулем AI (если включён):** сложные описания отдаются LLM, ответ строго JSON по схеме действий.
- Не найденное помечается «⚠ не найдено, укажите путь».

### §5.6 Импорт/экспорт
Экспорт папки/команды в `.jarvispack` (JSON). Импорт с проверкой схемы.

## §6 Голос Джарвиса (самое важное для «как в фильме»)

Как это делают Luxify и Priler/jarvis: **готовые записи фраз голосом Джарвиса из русского дубляжа** (в видео 28 видно действие `Sound.PlayWav C:\Program Files\Lux\JarvisVoice\...` и файл `Voice\Есть.wav`). Для произвольного текста используется нейросеть, обученная на этом голосе. Реализуем три уровня:

### §6.1 Уровень 1: пак фраз (0 RAM, мгновенно, основной)
- Структура `voices/jarvis/ru/{category}/*.wav` + `voice.json`. Категории: `greet` (по времени суток: «Доброе утро, сэр»…), `ok` («Да, сэр», «Есть», «Выполняю»), `loading` («Загружается»), `done` («Запрос выполнен, сэр»), `ready` («Всегда к вашим услугам, сэр»), `thanks` («Всегда рад помочь, сэр»), `status` («Всё в порядке, сэр…»), `not_found`, `no_internet`, `confirm`, `cancel`, `error`, `off`, `game_mode`, `joke`. Случайный выбор внутри категории без повторов подряд.
- Источники (Opus сам ищет и скачивает, затем нормализует громкость, режет тишину, раскладывает по категориям):
  - **github.com/FitoDomik/Jarvis-Sound**: 61 реплика Джарвиса из фильмов (русский дубляж) с таблицей текста («Да сэр», «Запрос выполнен сэр», «Всегда к вашим услугам сэр», «Загружаю сэр», «Есть», «Как пожелаете»…). Это и пак фраз, и датасет для §6.2.
  - **Priler/jarvis** `resources/sound/voices` (`jarvis-og`, `jarvis-remaster`, `jarvis-howdy`): готовые ответы по категориям.
  - Сайты со звуковыми схемами «Jarvis voice pack» (61 реплика из 1-го и 2-го фильма) и прочие найденные вырезки. Нашёл — скачал — проверил на слух через STT, что текст совпадает.
  - Вырезки пользователя из фильма (кладёт в `tools/voice-train/data/raw/`).
- Недостающие фразы генерируются уровнем 2 и кэшируются в WAV.
- Пользователь может добавить свои WAV (вырезки из фильма) через вкладку «Озвучка».

### §6.2 Уровень 2: нейро-TTS голосом Джарвиса офлайн (для любого текста)
- Рантайм: **Piper/VITS ONNX через sherpa-onnx** на CPU (быстрее реального времени, ~60 МБ модель, выгрузка при простое).
- Модель голоса делается **один раз** пайплайном `tools/voice-train/` (Python) **локально на RTX 3060 6 ГБ** (fp16, batch 8–16; перед обучением закрыть Chrome и лишнее, т.к. RAM 8 ГБ). В рантайме GPU не нужна. Готовая модель кладётся в релиз, пересобирать не нужно:
  1. Датасет: реплики из Jarvis-Sound + Priler + вырезки пользователя (текст берётся из таблиц/распознаётся STT и проверяется) + синтетика: 1–2 тыс. русских предложений озвучиваются базовой Piper-моделью `ru_RU-denis/dmitri/ruslan` и прогоняются через **RVC v2-модель голоса Джарвиса (RU)** (есть готовая: huggingface `dragoncrack/jarvis`, найдена через voice-models.com). Получаем чистый датасет голосом Джарвиса.
  2. Fine-tune Piper с русского чекпоинта (22050 Hz, mono), экспорт в ONNX + `.onnx.json`.
  3. Скрипт `make_clips.py` генерирует недостающие клипы уровня 1.
- Эффект «как в фильме»: лёгкая пост-обработка (EQ + короткий reverb/«металлический» оттенок, тумблер) в рантайме.
- Fallback, пока модель не обучена: базовый Piper RU-голос с той же обработкой.

### §6.3 Уровень 3: Windows SAPI
«Голос Windows: встроенный, работает без интернета». Самый лёгкий fallback.

### §6.4 Экран «Синтез речи» (видео 26)
Карточки выбора движка с радиокнопкой: **Джарвис (фразы + нейро, офлайн)**, **Голос Windows** («встроенный, работает без интернета»), опционально онлайн-плагины (OpenAI / Fish Audio, по умолчанию выключены, ключ вводит пользователь). Для выбранного: «Голос: Джарвис», слайдер «Скорость 1.10×», кнопка ▶ предпрослушивания, анимированная волна.
Паки голосов персонажей (вкладка «Озвучка» в Дополнениях): Джарвис по умолчанию; формат позволяет добавлять Пятницу, Эдит и др.

> Все ассеты (голосовые WAV, модель голоса, Vosk, wake word) хранятся **не в истории git** (чтобы репозиторий не весил гигабайты), а в GitHub Release `assets-v1` приватного репозитория и **вшиваются в установщик Full**. Пользователь качает один установщик из Releases, и всё работает сразу. `tools/fetch-assets.ps1` собирает ассеты из источников и заливает их в релиз (`gh release upload`).

## §7 Локальный ИИ (Jarvis AI) — ОПЦИОНАЛЬНЫЙ модуль, выключен по умолчанию

> Делается последним этапом (M13). Ядро от него не зависит. **Исключение: §7.4 (презентация по шаблону) и §7.5 (диалоги) — часть ядра, делаются без LLM в M7.** Включается тумблером «Jarvis AI» в настройках с предупреждением о ресурсах. Пока модуль выключен, пункт «Jarvis AI» в сайдбаре открывает экран с описанием и кнопкой «Включить».

### §7.1 Модель и железо
- Детект железа (VRAM через DXGI, свободная RAM). Для целевого ноутбука (RTX 3060 6 ГБ, RAM 8 ГБ) — **3B–4B instruct Q4_K_M, все слои на GPU** (`-ngl 99`, контекст 4096, `--no-mmap` не использовать), чтобы RAM почти не расходовалась. Если свободной RAM < 1 ГБ — предупредить и не запускать.
  - Нет GPU: LLM не предлагать (или 1.5B на CPU по явному желанию).
  - ≥ 12 ГБ VRAM: 8B–14B.
- Семейство: актуальное открытое instruct-семейство с хорошим русским и tool-calling (на момент разработки проверь на Hugging Face; ориентир: Qwen3-класс). GGUF-файл выбирается в настройках (скачать один раз или указать файл с диска).
- `llama-server` sidecar: старт по запросу, `idle_unload_sec` (по умолчанию 60), настройка «держать в памяти». Во время игры (fullscreen foreground) не запускать без явной команды.

### §7.2 Чат-окно (видео 26)
Окно с заголовком диалога («Погода и дела»), список диалогов, поле ввода с кнопками [+] [🎙] [➤], селектор модели. Пузыри сообщений. Индикатор «Ищу актуальную информацию…» при онлайн-инструментах. Карточки результатов: погода «+16° Москва», чек-лист «✓ Команды выполнены: Свернуть все окна, Включить музыку». Можно писать и говорить. Ответ озвучивается голосом Джарвиса (уровень 2) и стримится по предложениям.

### §7.3 Tool-calling
Инструменты для LLM: `run_command(id|phrase)`, `run_actions(actions[])` (с тем же подтверждением), `find_app(name)`, `get_system_info`, `get_weather(city)`, `get_news(topic)`, `get_currency(code)`, `web_search(q)`, `create_presentation(topic, slides)`, `set_timer`, `open_url`. Онлайн-инструменты без сети возвращают `NO_INTERNET` → Джарвис говорит фразу из §0.
Персона (system prompt): вежливый, ироничный британский дворецкий, обращается «сэр», отвечает коротко (1–2 предложения голосом), по-русски.

### §7.4 Презентация (видео 29) — работает и без LLM
«Создай презентацию по информатике на тему "Байты"» → **без LLM:** шаблон (титульный «Байты» + предмет в подзаголовке, слайды «Введение», «Основные понятия», «Примеры», «Вывод» с пустыми плейсхолдерами) — так и показано в видео; **с модулем AI:** LLM генерирует план и тезисы (5–8 слайдов) → PowerPoint COM: новая презентация, титульный слайд «Байты», слайды с контентом, тема оформления → «Да, сэр. Запрос выполнен, сэр.» Далее «Измени цвет темы на фиолетовый» → вариант цвета темы в открытой презентации. Если PowerPoint не установлен: генерация `.pptx` через библиотеку и открытие в установленной программе.

### §7.5 Диалоги без LLM (основной режим)
Частые вопросы отвечаются готовыми сценариями: «как дела» → «Все в порядке, сэр…», «ты тут?» → «Всегда к вашим услугам, сэр», «спасибо» → «Всегда рад помочь, сэр», «который час», «какое сегодня число», «расскажи шутку», «доброе утро» (приветствие по времени суток), «кто ты», «что ты умеешь». Реплики — клипы из пака (§6.1). Минимум 40 диалоговых интентов.

## §8 Онлайн-функции (только при наличии сети)
- Проверка сети: быстрый TCP/HTTP-пинг с кэшем 30 с.
- **Погода:** Open-Meteo (без ключа) + геокодинг города (город по умолчанию в настройках).
- **Курс валют:** ЦБ РФ `cbr.ru/scripts/XML_daily.asp` («Курс доллара» → «Доллар — 92,4 рубля, сэр» + по желанию открыть страницу в браузере, как в видео 27).
- **Новости:** RSS-ленты (список в настройках), зачитать 3 заголовка.
- **Веб-поиск:** открыть поиск в браузере по умолчанию. Для ИИ: опциональный API (ключ пользователя).
- Без сети: фраза `no_internet`, статус в истории «Нет сети».

## §10 Дополнительный функционал

### §10.1 Пульт с телефона (видео 26: «PC Control»)
- В ядре HTTP+WS сервер (выкл по умолчанию), порт настраивается. Пара по QR-коду (одноразовый токен, затем постоянный ключ устройства), только LAN.
- PWA «Jarvis PC Control» (тёмный стиль): Главная: Медиа (Пауза, Дальше, Громче, Назад, Тише), быстрые команды (избранное), поле «Сказать/написать команду» (текст → NLU), статус «Выполнено: Пауза», история. Кнопка микрофона телефона: запись → отправка аудио на ПК → STT на ПК.
- «Откуда угодно»: инструкция подключения через Tailscale/ZeroTier (без своего облака).

### §10.2 Профили рабочего окружения (идея из launcher)
Профиль: набор приложений/терминалов с позицией (монитор, половина экрана, поверх/позади), порядком запуска, «уже запущено → только переставить окно». Запуск голосом («рабочий режим»), хлопком, хоткеем, из трея. «Закрыть окружение» закрывает запущенное профилем.

### §10.3 Таймеры и напоминания
«Выключи компьютер через два часа» → `shutdown /s /t 7200` + уведомление + голосовая отмена «отмени выключение». «Напомни через 10 минут проверить духовку» → toast + голос.

### §10.4 Настройки (видео 26, 28)
Вкладки **Основные / Темы / Голос / ИИ / Горячие клавиши / Пульт / О программе**.
- *Режимы:* Чувствительность префикса (слайдер %), Фразы активации режимов (режим префикса / тихий режим / выключить микро, редактируемые поля).
- *Система:* В трей при закрытии, Автозапуск программы, Модель микрофона (выбор устройства, «По умолчанию»), индикатор уровня микрофона, Язык интерфейса.
- *Интерфейс/Темы:* Цвет темы (свотчи + свой), Прозрачность %, Размытие %, Анимации, Анимация аватара, HUD при активации, Окно поверх.
- *Голос:* §6.4. *ИИ:* §7.1. Импорт/экспорт всех настроек.

## §12 Производительность (измерять, не угадывать)
| Метрика | Цель |
|---|---|
| RAM в простое (трей, окно закрыто, префикс, Vosk выгружен) | ≤ 60 МБ (предел 100) |
| RAM во время команды (Vosk тёплый, окно закрыто) | ≤ 250 МБ, возврат к простою через `stt_keep_warm_sec` |
| CPU в простое | ≤ 1% |
| Wake word → загрузка Vosk → распознано (холодный старт) | ≤ 1,2 с от конца фразы |
| Wake word → реакция (звук/анимация) | ≤ 300 мс |
| Конец фразы → начало действия | ≤ 700 мс |
| Старт до трея | ≤ 2 с |
| Главное окно открыто | ≤ +150 МБ сверх простоя |
| Нейро-TTS | только для фраз, которых нет в паке; выгрузка через 60 с |
| LLM | выключен по умолчанию; если включён — в VRAM, выгрузка через 60 с |
| Настройка «Экономия памяти» | вкл по умолчанию; выкл = держать Vosk тёплым всегда (быстрее, +RAM) |
Главное окно: Svelte без тяжёлых библиотек, орб на Canvas 2D/WebGL. В настройках виден текущий расход RAM Джарвиса. Скрипт `tools/bench.ps1` меряет RAM (Private Working Set, включая дочерние WebView2) и CPU за 60 с простоя и пишет в CI-артефакт. Регрессия >20% валит CI.
